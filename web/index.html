rdna2-dis

AMD RDNA2 (gfx10.3) disassembler, written in Rust and running here as WebAssembly. Output matches llvm-objdump. Your code never leaves the browser.

Source on GitHub

Ctrl+Enter disassembles. You can also drop a raw code file anywhere on the page.
